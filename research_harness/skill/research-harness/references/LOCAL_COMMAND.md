# Local executable

Run `labweft` after `python -m pip install .`, or use
`python /absolute/path/to/LabWeft/labweft.py` from a clone.
The former `rh` command and `research-harness` Skill ID remain compatible.

The local installer replaces this file with the precise interpreter and launcher
on the user's machine. It does not overwrite their AGENTS.md or CLAUDE.md.
