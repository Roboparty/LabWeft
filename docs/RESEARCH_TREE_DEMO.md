# Research tree example

[简体中文](RESEARCH_TREE_DEMO.zh-CN.md)

## Generate and open

From the source checkout:

```sh
python labweft.py demo --scenario research-tree ./tree-preview --open --port 0
```

An installed checkout also supports `labweft demo` with the same arguments.
The preview is local and read-only; `--port 0` chooses a free port. No Shinka,
model account, GPU, Node.js, or network connection is required. Omit
`--open --port 0` to generate offline files only, then open `.research/map.html`.
Keep the complete workspace to serve or re-export it later.

## What is recorded

- Six directions: algebraic structure, symmetry and signs, lookup and memorization,
  discretization and approximation, numerical anomalies, and cross-branch combinations.
- 37 preset candidates, 36 primary lineage edges, and two secondary references.
- 49 actual saved CPU evaluations from 2026-10-01: 37 development evaluations and
  12 additional input checks.
- Four invalid candidates with their original errors; per-input predictions,
  metrics, source hashes, evaluator code, evidence references, and source dates.

These are synthetic teaching data. The portable fixture is
`research_harness/fixtures/research_tree.json`, generated by
`research_harness/research_tree_demo.py`; both are bundled in the package.
Machine-specific command paths were removed before inclusion.

**Generation replays saved results. It performs zero new CPU evaluations and
zero model calls, and does not invoke Shinka.** The candidates were preset,
not proposals from a live automatic search. For real execution, follow the
separate [backend guide](AUTORESEARCH.md).

First generation took about 1.9 seconds in one recorded Windows/Python 3.12.13
run on 2026-10-01. This is an observation, not a performance guarantee.

## Explore the canvas

- Pan, zoom, fit, expand the canvas, and fold descendants.
- Horizontal `L0/L1/...` columns indicate lineage depth, not time or generations.
- Vertical lanes represent research directions.
- Primary lineage is visible; secondary references can be toggled.
- Select a candidate to inspect its changes, metrics, and evidence. A recorded
  Run focus resolves to its owning condition; run provenance remains available
  in details.
- Switch to Outline for the semantic hierarchy.

The canvas takes visual inspiration from the public Simate RoboScientist
Evolution view and is independently implemented; see
[acknowledgements](../ACKNOWLEDGEMENTS.md). Recorded scores do not automatically
become scientific claims. Failures and unknown values remain visible.

## Generate again

Re-running the same command in the same example workspace preserves its project
identity and event history and refreshes the current renderer. The generator
refuses to replace an unrelated project or an incompatible example version.
The default `demo` still generates the smaller policy-study example; the tree
requires `--scenario research-tree`.
