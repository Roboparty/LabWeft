# 已知边界，不作为宣传结论

[English](LIMITATIONS.md)

当前代码是围绕已确认的“本地优先、单一对话、科研工作空间”设计制作的 alpha 原型，不是完整的 ClearML 替代品。

## 研究理解

扫描器不能推断研究动机，也不能重建未知的历史输入。这些工作由用户现有的宿主 agent 按 Skill 流程完成。格式正确的补丁仍可能包含错误的科研解释；模型输出及其来源支撑都需要独立评估。

自动解析仅覆盖少量已说明的 JSON/TOML/CSV 布局。YAML、Hydra 的最终配置、TensorBoard、W&B、ClearML、MLflow、自定义机器人日志与逐 episode 结果等，需要额外适配器或 agent 辅助规范化。现有源码检查提供 Python 符号索引，不能代替对梯度、信息泄漏、部署路径或动态导入的整程序分析。

目录清单、已采文件、解析的 Run 与核实的科学结论具有不同分母。许多文件是逐运行自动产物；一个来源可以支持多条结论，许多文件也可能不支持任何结论。有意抽样的来源或地图节点数不能证明整个项目已正确解读。旧版与修正版结果视图需要分别保留身份；一项实验完成也不代表后续扩展完成。

## 历史身份与统计

没有记录 Run ID 时，移动或重命名需要重新核对身份。跨文件夹重复的 ID 会被标记。当前文件清单不是训练时的代码快照。只记元数据的二进制文件没有可核验的内容身份；checkpoint 和谱系关系必须有实际记录的证据。

汇总在无歧义、来源报告完成的 seed 间计算描述性均值与样本标准差。不提供 bootstrap 置信区间、配对统计检验、等价性检验、实验预算优化、因果识别或自动排名。不同协议、配置与代码版本不会无提示合并。Seed 取自已记录字段，无法单凭字段证明随机数过程真正独立。若 Run 的来源证据变化或缺失，当前汇总会排除它并提示；历史快照仍可查看。这一机械处理不能判定旧科研结果在新协议下是否有效。

事件时间线记录 LabWeft 何时观察到文件变化或保存图对象变化，而非实验发生的时间。节点变更保留该 revision 的模块归属。文件按模块筛选依赖当前连接的证据，因此未被引用的历史文件只会出现在“全部变化”中，不一定命中模块筛选。
归档 Cell 不进入当前层级与数值比较。历史 claim、decision 及其证据仍可查看；这一状态不代表来源文件被删除，也不自动否定旧科研结论。

## 持久化与运维

一个工作空间可关联多个来源目录。跨项目总览、受控的跨项目知识共享与远端 worker 尚未实现。跨机器 Git 合并、网络文件系统锁、多方协作角色、schema 迁移及崩溃/断电耐久性需要进一步工作。

证据快照保存在本机，并被工作空间 Git ignore 排除。只复制事件索引**不会**备份或复制证据字节。工具不自动创建 GitHub 仓库、分支，不负责上传、同步、创建 issue/project、删除 checkpoint 或安排实验。

## Agent 接入

安装器与协议经过本地测试，有限范围的私有项目已在 Codex 客户端对话按 Skill 流程试用。新聊天的自动 Skill 发现及其他模型客户端尚未认证。发现行为会随客户端版本、策略、沙盒、托管设置和权限变化。没有文件系统/工具权限的裸模型无法自行使用本软件。本地核心无需隐藏的额外模型账号。

## 界面与安全

界面只读。刷新按钮只获取已经保存的状态，不启动来源扫描或语义推理；单对话流程由安装的 Skill 驱动。任意 schema 编辑仍需宿主 agent 或 CLI。已有本地/浏览器检查，但并未覆盖所有操作系统与浏览器组合。
界面提供中英文切换，节点可选提供标题/说明翻译；缺少翻译时回退原文，原始证据不会由界面机器翻译。离线 HTML 默认省略来源正文；显式 `--include-evidence` 最多复制 5 MiB 已索引文本快照，部分来源在该文件中仍无法打开，页面会标示省略。

这不是加固的公网服务。已知文件名排除规则不等于完整密钥扫描。所有来源文本都应作为不可信数据。文件哈希无法阻止有操作系统权限的用户恶意替换文件；`human:` actor 标签也不是密码学身份认证。仍需依靠宿主 agent 的沙盒及授权机制。
