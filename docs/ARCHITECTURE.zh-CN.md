# 架构 v0.1

[English](ARCHITECTURE.md)

## 产品约定

一个已有、具备工具能力的 agent 控制用户授权的工作流程；用户不必手动协调多个 agent。本地核心没有模型 SDK。Skill 说明领域流程，模型使用普通 shell 和文件工具。

扫描器只做事实提取。宿主 agent 检查来源与历史，再写语义补丁。核心验证补丁并持久化事务。前端是状态的只读投影，不是权威来源。

## 身份

科研工作空间的项目 ID 在 `manifest.json` 中生成和保存，不从目录、Git remote 名称或分支推导。来源具有明确别名及本机路径。Run 优先采用记录中的 `run_id`，否则退化为“来源别名 + 相对运行目录”并清楚标注。

没有明确身份的文件夹重命名需要重新核对；配置或哈希相同仍不足以合并科研身份。同一 Cell 下出现变化的配置会被标记并从汇总中排除，不会无声重分配。新的独立 seed 属于不同 Run。共享 baseline 是同一组 Run，由多个研究问题引用。

## 持久化

权威状态是按序排列的事件目录。每个事件记录 revision、前一个哈希、时间戳、actor、原因和更新的对象。写入使用本地进程锁及预期基准 revision；事件先落到临时文件，再原子改名。读取时重放并核验事件链。旧状态不会由 LLM 重新生成。相同内容不新增 revision；失败的验证不会留下部分更新。

这种方式能检测意外损坏，但不是密码学签名或只能追加的文件系统。具有操作系统权限的用户仍可重写文件并重算哈希。它不是分布式系统；Git 并发修改需人工协调。历史重放耗时随事件数线性增长。生产化还需要快照和 schema 迁移，但缓存不能成为权威状态。

## 事实与判断

`module`、`question`、`cell`、`run`、`evaluation`、`claim`、`decision`、`artifact` 是图中的对象。`parent_id` 负责导航树；类型化边表示比较、支持、矛盾、派生、checkpoint 继承等明确关系，不代表因果自动得到证明。

证据引用把文件 ID 绑定到内容哈希及定位信息。已人工确认的 claim 和 decision 必须有直接不可变来源及适用范围。链接的节点 ID 方便导航，不是独立证明。后续来源变化会提示重新核对适用性，但不抹掉旧快照。

Decision 包含必要上下文、覆盖的因素取值、重复验证键与重新开启的条件。只有明确人工确认后，才可作为批准复用的历史判断。未知或额外条件应进入复核，不会自动发起训练。CLI 无法在拥有任意 shell 权限的 agent 面前充当安全边界；仍需宿主权限与用户授权。

## 数据适配器

核心原生识别 `metrics.json`、`results.json`、`metrics.csv`、`config.json`、`config.toml` 和可选的 `run.json`。同一 Run 目录按上述指标文件优先级选择首个文件；其余来源列入清单并提示，不会无声合并。如果主指标文件消失，另一文件成为主来源，Run 进入 `needs_review`，保留旧证据直到 agent 核对该切换。指标、run 和配置来源的协议字段矛盾也阻止汇总。CSV 取最后一行，不自行编造“已完成”；JSON 必须有明确完成标记才能进入汇总。

大型二进制文件只记录元数据，不加载 pickle/torch。已知敏感文件名、符号链接和依赖/内部目录会排除。Python 源码只通过 AST 静态解析。YAML 与任意其他文件保留供宿主检查；不执行输入文件中的指令。

覆盖范围分层记录：目录盘点、已选取且校验的来源字节、索引文件、agent 映射的图对象、独立重放的实验分别有自己的分母。已选文件不等于独立实验。若项目有修正后的结果或后续分支，agent 应依据来源分别记录其身份与完成范围。

## 界面

随包 HTML/CSS/JS 不使用 CDN、前端构建或运行时依赖。本地 HTTP 服务仅提供状态与指定文本证据；绑定 loopback、检查 Host、要求随机 API token，并拒绝跨站请求。没有 shell、文件写入、实验启动或同步的 HTTP 接口。

离线导出嵌入一次状态快照，默认不附来源正文。`--include-evidence` 显式嵌入已索引的文本快照，包括尚未连接语义节点的索引文件；所有嵌入文本合计上限 5 MiB。离线来源列表会标出被省略的正文并禁用打开按钮。JSON 会转义 `<`、`>`、`&` 和 Unicode 分隔符；前端转义动态标签，并用 `textContent` 显示证据。导出文件仍是私有产物，公开前必须审阅。

`export-site` 为每个工作空间生成独立快照，再生成 `index.html` 入口。顶部项目切换只负责页面导航，不混合各项目的状态、证据、Cell 对比或历史。第一个工作空间是站点默认项目；嵌入来源正文仍需对整个私有站点显式选择。

静态界面的 `中文 / English` 切换默认中文，并在本机保存选择。节点可选填 `attrs.i18n.zh` / `attrs.i18n.en` 的标题和说明；缺少翻译时显示原始记录。切换不会翻译来源证据，也不会改写事件。研究历程只展示带有明确来源日期及直接证据的项目事件，区分发生日、阶段起点与报告截至日。独立的“记录修订”从每次 LabWeft 事件提取文件、节点和关系变更；节点变更保留该 revision 的模块归属，文件模块筛选则依赖当前证据引用。修订时间记录 LabWeft 的观察或写入，不应冒充历史实验时间。节点 `archived` 只是 LabWeft 记录状态，不表示来源文件或外部项目归档被改变。
归档 Cell 不进入当前地图层级和数值比较；归档的 claim 与 decision 仍在历史决策列表中显示，并可查看证据。归档不删除其来源快照。

## 宿主边界

Codex 与 Claude 的 Skill 放在各自发现路径；通用 agent 可读取同一 Skill 与命令协议。这是基于能力的接入：宿主必须能读取文件并执行命令。它不是 API 路由器、模型回退服务、OAuth 代理或通用兼容保证。
