# LabWeft brand assets

The original mark combines alternating woven strands: evidence, experimental
lineage, and research decisions. Forest green, sage, and gold are used across
the mark and bilingual banners.

Assets in `docs/assets`:

- `labweft-mark.svg` and `.png`: square mark; the bundled UI uses the same
  geometry inline, including in offline exports.
- `labweft-banner.en.svg` / `.png` and `labweft-banner.zh-CN.svg` / `.png`:
  English and Chinese README banners.
- `labweft-social-preview.png`: 1280 × 640 repository social preview.

Vector lettering is outlined, so visitors do not need fonts or external assets.
The banners contain no project data. These original assets use this repository's
[MIT license](../LICENSE); no third-party logo or artwork is included.

The social preview can be uploaded in GitHub repository Settings → General →
Social preview. Including the file in the repository alone does not configure
GitHub's preview setting.
