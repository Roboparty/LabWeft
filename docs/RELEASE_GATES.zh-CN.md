# 发布与可靠性门槛

[English](RELEASE_GATES.md)

LabWeft 当前是本地 alpha 原型。`validate` 通过只表示存储结构与引用的文本快照在内部一致；它不能证明 agent 对科研内容的解释正确。单元测试或一次私有试用不足以认定某个构建可正式发布，也不足以声称达到成熟平台的可靠性。

| 门槛 | 所需证据 | 当前状态 |
|---|---|---|
| 来源与增量更新 | 公开的合成多阶段材料覆盖新增文件夹、删除或修改指标、旧协议文件接管、重复扫描、独立 seed 和受保护修正。过时结果不得无提示进入当前比较。分别记录目录盘点、采集、语义映射与核验的分母。 | 核心回归与选取来源的私有试用在本地通过。私有试用只是覆盖抽样，尚非完整解读；可复用的公开 agent 评测材料和盲法评分仍未完成。 |
| 研究解释 | 独立 agent 从原始证据重建研究目的、条件、协议和完成范围；公开评分准则统计错误结论、遗漏证据和不必要的新实验建议。 | 已有有限范围的私有试用和内部独立核查。历史与修正视图、已完成工作与后续扩展必须分别保留身份；尚未通过通用基准。 |
| 双语界面与事件历史 | 在本地与离线页面验证默认中文、英文切换、可选节点翻译及原始节点文案回退、省略标记、文件/节点/关系时间线、模块筛选和可访问导航。 | 有限范围离线浏览器检查通过，包括 27/27 项历史回归和较新的 48/48 项界面/键盘回归，均无浏览器错误；安装包界面和所有历史重归属情形仍未逐项验证。 |
| 打包 | 构建 wheel 与 sdist，在干净的 Python 3.11+ 环境中分别安装，并验证 CLI、随包 Skill 和离线界面。 | wheel 与 sdist 曾在彼此独立的 Windows Python 3.14 干净环境中构建安装；此前构建的 CLI 示例、验证、比较、导出及 Skill 安装通过。最新界面修改后仍需重建复验；其他 Python/操作系统组合仍待验收。 |
| 客户端与平台 | 在新的客户端对话中，按支持的操作系统/Python 组合执行完整流程，记录版本、权限及失败。 | 当前 Codex 客户端对话和 Windows 本地核查完成；新聊天 Skill 自动发现、其他客户端及受支持 Linux/macOS 的实跑仍未完成。 |
| 隐私与安全 | 检查来源排除、导出和服务端点防护；建立非公开漏洞报告渠道，并在发布前扫描凭据和私有研究文本。 | 已有核心边界测试，并记录了可达源码/历史的发布扫描。GitHub 私密漏洞报告于 2026-10-03 启用并核验；全面对抗性安全审查仍未完成。 |
| 维护与权属 | 发布前确认维护者/权属、第三方声明、支持预期和仓库可见性。 | 已有 MIT 源码许可证及贡献说明。仓库所有者于 2026-10-03 明确授权公开工具源码；GitHub 公开可见性已于 2026-10-03 设置并核验，私有研究工作空间不包含在内。这项授权不代表上方可靠性门槛已全部完成。 |

详细本地测试历史见[验证记录](VALIDATION.zh-CN.md)，已知技术边界见[已知边界](LIMITATIONS.zh-CN.md)。私有试用数据与地图必须留在工具源码仓库之外。
