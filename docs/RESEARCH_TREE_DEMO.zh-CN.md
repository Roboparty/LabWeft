# 快速生成研究树示例与交接记录

[English](RESEARCH_TREE_DEMO.md)

## 一条命令生成并打开

在 LabWeft 源码目录中运行：

```sh
python labweft.py demo ./tree-preview --scenario research-tree --open --port 0
```

已经安装 LabWeft 时可以使用：

```sh
labweft demo ./tree-preview --scenario research-tree --open --port 0
```

`--port 0` 自动选择空闲端口，避免占用已有服务；`--open` 启动本机只读预览并打开浏览器。
不需要 Shinka、模型账号、GPU、Node.js 或网络。2026-10-01 本机 Windows/Python 3.12.13
首次生成实测约1.9秒；这只是单次观察，不是所有机器的性能保证。

仅生成离线文件时去掉 `--open --port 0`，打开输出目录中的 `.research/map.html` 即可。
离线页已包含本示例的合成源码和证据快照。保留整个 `tree-preview` 目录可继续浏览、
重新导出或启动服务；原始开发机路径不是使用条件。

## 保存了什么

- 六条路线：代数结构、对称性与符号、查表与记忆、离散化与近似、数值异常、跨分支组合。
- 37个预设候选、36条主继承关系和2条次级参考关系。
- 2026-10-01 实际CPU评测保存的49份结果，包括37次开发集评测和12次额外输入检查。
- 四个无效候选的原始错误，以及逐输入预测、指标、源码哈希和评价程序。
- 完整的证据引用、来源日期与回放标记；发布前已去除执行命令中的本机绝对路径。

数据保存在包内 `research_harness/fixtures/research_tree.json`，生成器在
`research_harness/research_tree_demo.py`。安装后的 wheel 同样携带该数据，不依赖当前会话
或临时文件夹。数据是教学任务，不含 Luna 的私有实验记录。

**快速生成回放已保存的结果，不会重新执行49次评测，也没有运行Shinka自动提案。**
每个运行记录都注明保存结果来源，生成命令返回本次新增CPU评测0、模型调用0。
真实自动研究请使用单独的[Shinka后端流程](AUTORESEARCH.zh-CN.md)。

## 界面约定

当前研究树借鉴 Simate RoboScientist 公开 Evolution 画布的表达方式，由 LabWeft 独立实现：

- 默认显示一张树形画布，节点只保留短编号和来源明确的状态颜色。
- 横向 `L0/L1/...` 是派生层级；纵向是研究方向，不把它们冒充真实实验时间或代数。
- 主继承线直接显示；次级参考关系可以开关。
- 点击节点显示简洁检查面板；长说明、指标和证据按需展开。
- 支持拖动、缩放、适应画布、展开画布和后续分支折叠；大纲仍可切换。
- 不根据分数擅自推断科学结论，也不删除失败或将未知值当成零。

## 重复生成与保存边界

对同一个示例目录再次运行相同命令，会保留项目ID与已有事件历史，只重新导出当前版本
的前端。这适合更新界面后快速预览。新示例数据版本、其他示例或真实项目须使用新目录，
生成器不会覆盖它们。当前示例数据与生成器已随 `main` 分支一起保存。

原有 `demo` 默认仍生成 policy 示例；本功能必须选择 `--scenario research-tree`。
